# Security Policy

## Supported Versions

We take security seriously. Currently, we provide security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within EGFootball5, please send an e-mail to our security team. We will review all security vulnerabilities and do our best to address them in a timely manner.

Please include the following information in your report:
* Type of vulnerability (e.g., XSS, SQLi, CSRF, etc.)
* Steps to reproduce the vulnerability
* Any potential impact or risk associated with the vulnerability

We will reply to your report within 48 hours to acknowledge receipt and outline the next steps. Please do not disclose the vulnerability publicly until we have had a chance to address it.

Thank you for helping keep EGFootball5 secure!
